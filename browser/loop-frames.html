Looping frames (TEST ONLY, ALT-1731)

A page built to be too tangled for the twin's in-page scripts. It nests itself in frames (?depth=, default 0, stops at 4; same origin) and makes every frame answer with the top document (?cycle=0 turns that off) and, on the top page only, adds ?hosts= elements (default 11000) that each hold an open shadow root, more than the 10000 roots one in-page script may walk. Use ?hosts=0 for the plain nested frames.
